# Program dossiers

This directory is for **optional program-level notes only**.

The canonical database is `../registry/programs.jsonl`. You do not need a Markdown file for every registry entry.

Create `programs/<slug>/PROGRAM.md` only when a program needs richer notes such as:

- complex scope or exclusions;
- multiple official security pages;
- detailed reward / payout terms;
- KYC or eligibility nuances;
- a longer material-change history;
- unresolved program-level questions worth revisiting.

Do **not** store vulnerability findings, PoCs, exploit evidence, individual report drafts, severity assessments, or submission-response tracking here.

Use `PROGRAM_TEMPLATE.md` when a dossier is useful.
