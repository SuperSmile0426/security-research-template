# Watchlist

The registry remains the identity source of truth. A watchlist entry should reference an existing `BP-XXXX` ID whenever possible.

Typical triggers:

- announced bounty not yet open;
- testnet/mainnet launch pending;
- security page exists but rewards are not yet funded;
- program paused temporarily;
- private program awaiting access;
- reward / scope expansion announced but terms not published.
